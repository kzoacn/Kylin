\section{性能评估}
\label{sec:performance}

本节给出征集要求所需的性能分析与基准数据。当前仓库对打包的 Kylin NGCC 实例使用仓库本地测量结果。

\paragraph{性能分析。}
在设计层面，Kylin 的主要开销来自哈希与 XOF 调用。密钥生成需要构造超树顶层；签名需要计算 BPORS+FP 相关材料，并在超树的每一层上计算一条认证路径；验证则需要重建 BPORS+FP 公钥并验证超树签名。\WOTSCS\ 减少了每个一次性签名中 $n$ 字节元素的数量，BPORS+FP 减少了底层少次签名载荷，而 Diverse Layer Heights 则在 $h$ 不能被 $d$ 整除时，仍然使签名阶段的哈希调用代理计数保持平衡。

\paragraph{基准平台。}
软件实现使用 ISO C 编写，并采用 GCC 13.3.0。参考实现保持默认的 \texttt{-O2} ISO C 编译配置，并启用常规告警检查。优化后的 64 位 PC 实现使用以 \texttt{-O3 -march=native} 为核心的目录级构建选项；其中 \texttt{Kylin-128} 还额外启用了链接时优化、省略帧指针、循环展开以及 \texttt{-fno-plt}。基准主机为 x86-64 64 位 PC 环境：AMD Ryzen 7 7800X3D 8-Core Processor，8 个物理核心、16 个硬件线程，\texttt{/proc/cpuinfo} 报告主频约为 4.192 GHz，内存 30 GiB，操作系统为 Ubuntu 24.04.3 LTS，运行于 Linux 6.18.33.1-microsoft-standard-WSL2。实现中使用 ICCS 辅助哈希/XOF 接口 \texttt{sm3hash}、\texttt{pseudohash} 与 \texttt{pseudoXOF}；报告中的打包基准不依赖外部密码学库。
