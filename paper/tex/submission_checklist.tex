    \item A submission-style security-claim table for the selected NGCC 128/256/512-bit families has now been added in \cref{tab:ngcc-parameters}. \todo{If desired, add a supplementary note explaining how the single-key $q=2^{64}$ tuning used for parameter selection relates to the evaluation document's broader ``at most $2^{80}$ queries'' convention.}
    \item The recommended families now use $h=70$ and are tuned with $q=2^{64}$, which supports the call's requirement of at least $2^{64}$ signatures under one key pair in the intended single-key model. The packaged NGCC SIG wrapper explicitly accepts messages up to $2^{60}$ bytes, i.e.\ $2^{63}$ bits.

    \item Repository-local benchmark and memory summaries for all six packaged implementations are now generated automatically and recorded in \texttt{paper/data/package\_bench.csv} and \texttt{paper/data/package\_memory.csv}.
