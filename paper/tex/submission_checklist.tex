\section{Packaging Checklist and External Deliverables}
\label{apx:submission-checklist}

This appendix records the repository-local status of the NGCC submission-package components.

\subsection{Algorithm Text}

\begin{itemize}
    \item A submission-style security-claim table for the selected NGCC 128/256/512-bit families has now been added in \cref{tab:ngcc-parameters}, with a single-key $q=2^{64}$ concrete-security setting aligned with the packaged instances.
    \item The recommended families now use $h\in\{62,65,64\}$ and are tuned with $q=2^{64}$, which supports the call's requirement of at least $2^{64}$ signatures under one key pair in the intended single-key model. The packaged NGCC SIG wrapper explicitly accepts messages up to $2^{60}$ bytes, i.e.\ $2^{63}$ bits.
    \item A submission-style correctness statement for the packaged instances now appears in \cref{sec:security-claims}.
    \item The security section now states the current scope of the side-channel, multi-key, and repeated-key claims explicitly: the first-stage software package makes no dedicated side-channel-hardening claim, uses single-key analysis by default, and targets $q=2^{64}$ repeated-key usage for one long-term key pair.
    \item Repository-local benchmark summaries for the packaged implementations are generated automatically and included in the repository materials.
    \item Optional 32-bit embedded-platform and hardware-platform benchmarks are outside the current first-stage package and can be added as separate evidence if requested.
\end{itemize}

\subsection{Required Forms and Statements}

\begin{itemize}
    \item The signed algorithm basic-information form for the submitters and designated contact person is provided as the external package-root PDF \texttt{算法基本信息.pdf}.
    \item The signed submitter intellectual-property statement is provided as the external package-root PDF \texttt{知识产权声明.pdf}.
    \item Patent-owner or patent-applicant statements are external signed materials only if relevant rights are disclosed.
    \item The ownership statement for the reference and optimized implementations is covered by the signed external intellectual-property materials.
\end{itemize}

\subsection{Implementation Package}

\begin{itemize}
    \item First-stage ISO C reference implementations are now present for \texttt{Kylin-128}, \texttt{Kylin-256}, and \texttt{Kylin-512}.
    \item First-stage optimized 64-bit PC implementations are now present for all three instances; they share the portable code path with an optimized build profile and selected SIMD/hash fast paths.
    \item The implementations use the NGCC SIG API helper package provided for the call.
    \item A repository-local \texttt{README} for the implementation package has been added.
    \item The three $q=2^{24}$ companion implementations are now organized as additional non-primary submission artifacts.
    \item Automated package-level benchmark generation is now part of the repository workflow and feeds the table in \cref{tab:kylin-package-bench}.
    \item The main document now summarizes the implementation package, test-vector package, and intellectual-property package explicitly in \cref{sec:implementation-codes,sec:test-vectors,sec:ip-statements}.
\end{itemize}

\subsection{Test Vectors}

\begin{itemize}
    \item Known-answer test vectors for all three submitted instances have been generated using the standard NGCC KAT driver.
    \item The generated test-vector outputs for the three submitted instances are now included with the repository materials.
    \item The reference build scripts regenerate and copy the published test vectors with \texttt{make kat}.
\end{itemize}
