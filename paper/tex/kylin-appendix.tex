
\section{Parameter Evaluation Sage Script}
\label{apx:script} 
The script below evaluates parameter candidates with per-layer hypertree heights
$(h_0,\ldots,h_{d-1})$ satisfying $\sum_{i=0}^{d-1} h_i = h$. It uses $h_0$ for
the message-digest index split and uses $\sum_{i=0}^{d-1} 2^{h_i}$ in the HT
hash-call proxy. The currently frozen rows include the packaged
$q=2^{64}$ tuples \texttt{Kylin-128/256/512} and the companion $q=2^{24}$
tuples \texttt{Kylin-128-q24/256-q24/512-q24}.

\section{\texorpdfstring{$q=2^{24}$}{q=2 to the 24} Companion Parameter Profiles}
\label{apx:q24-profiles}

This appendix summarizes the frozen companion $q=2^{24}$ profiles that are
kept as additional implementations. The motivation is practical:
some application settings remain dissatisfied with large signature sizes and
verification-time behavior under very large per-key signing budgets. In
addition, NIST's April 13, 2026 initial public draft SP 800-230 highlights
stateful hash-based signatures with explicit per-key usage bounds, which
further motivates keeping explicit companion rows for limited-signature
operating points (including $2^{24}$-style limits)~\cite{NIST:SP800-230-IPD}.

In this repository, the $q=2^{24}$ rows are selected from the same constrained
search workflow and then frozen as additional companions to the packaged
NGCC $q=2^{64}$ families.

The optimized implementations apply macro-unrolled SM3 compression, SSE2/AVX2
hardware dispatch for message-word loading, a malloc-free \texttt{pseudoXOF}
fast path for byte-aligned input, and 4-way SSE2 WOTS chain acceleration
adapted for $n=16/32/64$.  Both the sign and verify paths batch 4~WOTS chains
per SIMD operation.
