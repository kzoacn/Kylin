\subsection{Generation and Coverage}

\begin{itemize}
    \item The published vectors follow the NGCC digital-signature KAT naming convention and cover each of the three primary submitted instances.
    \item They are generated with the ICCS KAT driver and deterministic random-generator interface required by the call.
    \item The reference implementation package includes automated support for regenerating the published vectors, which keeps the implementation tree and the distributed vector set synchronized.
    \item The companion $q=2^{24}$ implementations can also regenerate vectors through the same workflow if supplementary vectors are requested, but the primary published KAT set is limited to the three submitted NGCC instances.
\end{itemize}
