\section{Test Vectors}
\label{sec:test-vectors}

digital-signature instances submitted to NGCC and the three companion
$q=2^{24}$ profiles.  These vectors are intended to verify correctness and
interoperability of the packaged implementations.

\subsection{Generation and Coverage}

\begin{itemize}
    \item The published vectors follow the NGCC digital-signature KAT naming convention and cover all six packaged instances.
    \item They are generated with the ICCS KAT driver and deterministic random-generator interface required by the call.
    \item The reference implementation package includes automated support for regenerating the published vectors, which keeps the implementation tree and the distributed vector set synchronized.
    \item The companion $q=2^{24}$ vectors use the same deterministic workflow under the retuned BPORS+FP parameters.
\end{itemize}
