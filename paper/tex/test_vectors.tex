\section{Test Vectors}
\label{sec:test-vectors}

The submission package includes known-answer test vectors for the three primary
digital-signature instances submitted to NGCC.  The three companion
$q=2^{24}$ profiles were retuned after the last vector generation and are
marked as pending refresh.  These vectors are intended to verify correctness
and interoperability of the packaged implementations.

\subsection{Generation and Coverage}

\begin{itemize}
    \item The published vectors follow the NGCC digital-signature KAT naming convention and currently cover each primary instance.
    \item They are generated with the ICCS KAT driver and deterministic random-generator interface required by the call.
    \item The reference implementation package includes automated support for regenerating the published vectors, which keeps the implementation tree and the distributed vector set synchronized.
    \item The companion $q=2^{24}$ implementations regenerate vectors through the same workflow, but those vectors must be rerun for the current legacy-target parameters.
\end{itemize}
