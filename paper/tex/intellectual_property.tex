\section{Intellectual Property Statements}
\label{sec:ip-statements}

The NGCC call requires the technical package to be accompanied by signed intellectual-property materials. For the Kylin submission package, the required statement set is organized into the following three categories:

\begin{enumerate}
    \item A statement by each algorithm submitter, covering originality, disclosure, public evaluation, and the absence or disclosure of potentially relevant patents or patent applications.
    \item A statement by each relevant patent or patent-application owner, if any such rights may cover the algorithm or its implementations.
    \item A statement by the owners of the reference and optimized implementations, covering their availability for evaluation and possible later standardization use.
\end{enumerate}

These materials are external signed submission forms rather than technical chapters of the algorithm specification itself. The current repository tracks their completion status in Appendix~\ref{apx:submission-checklist}; the finalized names, affiliations, signatures, and any patent disclosures are to be inserted in the final submission packet that accompanies this specification and the packaged code.
