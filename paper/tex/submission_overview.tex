\section{Submission Package Overview}
\label{sec:submission-overview}

This draft is organized as the first-stage NGCC digital-signature submission package for \emph{Kylin}, the submission name used in this repository for the \SPHINCSA-based construction. The document now follows the package order requested in the NGCC submission requirements: overview and basic information first, then the algorithm specification, followed by implementation codes, test vectors, and intellectual-property materials. Whenever the current repository does not yet contain finalized external deliverables, we mark the gap with \todo{...}.

The electronic submission package is centered around this specification, the packaged implementation tree, and the generated test vectors. The printed package required by the call is narrower: it mainly consists of signed hard copies of the basic-information form and the intellectual-property statements that accompany the technical package.

\subsection{Conformance Notes for the Current Draft}

\begin{itemize}
    \item The package includes NGCC-oriented Kylin families covering the required 128/256/512-bit classical security levels with the corresponding 80/128/256-bit generic quantum targets; see \cref{tab:ngcc-parameters}.
    \item The packaged NGCC rows are tuned with $q=2^{64}$ in the concrete-security formulas and use hypertree heights $h\in\{56,58,62\}$, allowing the submission text to state support for at least $2^{64}$ signatures under one long-term key pair in the intended single-key setting.
    \item The packaged NGCC SIG wrapper accepts message lengths up to $2^{60}$ bytes, i.e.\ $2^{63}$ bits, matching the message-length bound stated in the call.
    \item The reference and optimized software packages, together with the published test vectors, are already present in the repository. Remaining signed forms and ownership statements are external submission materials tracked in Appendix~\ref{apx:submission-checklist}.
\end{itemize}
