\section{Submission Package Overview}
\label{sec:submission-overview}

This specification is organized as the first-stage NGCC digital-signature submission package for \emph{Kylin}, the submission name used in this repository for the \SPHINCSA-based construction. The document follows the package order requested in the NGCC submission requirements: overview and basic information first, then the algorithm specification, followed by implementation codes, test vectors, and intellectual-property materials. External signed forms are carried as package-root PDF files rather than duplicated in the technical specification.

The electronic submission package is centered around this specification, the packaged implementation tree, and the generated test vectors. The printed package required by the call is narrower: it mainly consists of signed hard copies of the basic-information form and the intellectual-property statements that accompany the technical package.

\subsection{Conformance Notes for the Current Draft}

\begin{itemize}
    \item The package includes NGCC-oriented Kylin families covering the required 128/256/512-bit classical security levels with the corresponding 80/128/256-bit generic quantum targets; see \cref{tab:ngcc-parameters}.
    \item The packaged NGCC rows are tuned with $q=2^{64}$ in the concrete-security formulas and use hypertree heights $h\in\{62,65,64\}$, allowing the submission text to state support for at least $2^{64}$ signatures under one long-term key pair in the intended single-key setting.
    \item The packaged NGCC SIG wrapper accepts message lengths up to $2^{60}$ bytes, i.e.\ $2^{63}$ bits, matching the message-length bound stated in the call.
    \item The reference and optimized software packages, together with the published test vectors and signed external PDF materials, are already present in the repository package inputs.
\end{itemize}
