\begin{abstract}
This document presents the first-stage NGCC digital-signature submission package for \emph{Kylin}, the submission name used in this repository for the \SPHINCSA-based stateless hash-based signature construction. The package retains the original technical specification and security discussion of \SPHINCSA\ as supporting material, while reorganizing the repository around the artifacts required by the NGCC public-key algorithm call.

The current package contains three NGCC instances, \texttt{Kylin-128}, \texttt{Kylin-256}, and \texttt{Kylin-512}, together with portable ISO C reference implementations, optimized 64-bit PC implementations, generated known-answer test vectors, automated build scripts, and reproducible parameter-search workflows. The packaged code uses the ICCS SIG API, routes hash/XOF functionality through the ICCS auxiliary interface, and uses the ICCS DRNG interface for KAT-mode randomness. The currently frozen implementation tuples are \texttt{Kylin-128} $(h,d,a,k,w,l)=(65,9,13,11,73,22)$, \texttt{Kylin-256} $(68,10,13,22,54,46)$, and \texttt{Kylin-512} $(66,11,13,49,97,79)$, while companion $q=2^{24}$ profiles are retained as reference-only additional implementations.
\end{abstract}
