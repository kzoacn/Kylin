\begin{abstract}
This document presents the first-stage NGCC digital-signature submission package for \emph{Kylin}, the submission name used in this repository for the \SPHINCSA-based stateless hash-based signature construction. The package retains the original technical specification and security discussion of \SPHINCSA\ as supporting material, while reorganizing the repository around the artifacts required by the NGCC public-key algorithm call.

The current package contains three NGCC instances, \texttt{Kylin-128}, \texttt{Kylin-256}, and \texttt{Kylin-512}, together with portable ISO C reference implementations, optimized 64-bit PC implementations, generated known-answer test vectors, automated build scripts, and a reproducible parameter-selection script. The packaged code uses the ICCS SIG API, routes hash/XOF functionality through the ICCS auxiliary interface, and uses the ICCS DRNG interface for KAT-mode randomness. The first-stage implementation fixes the common shape $(h,d,a,w)=(70,10,14,64)$ and currently focuses the remaining work on final submission forms, deeper performance evidence, stronger optimization, and final security-exposition polish rather than on package scaffolding.
\end{abstract}
