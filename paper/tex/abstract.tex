\begin{abstract}
This document presents the first-stage NGCC digital-signature submission package for \emph{Kylin}, the submission name used in this repository for the \SPHINCSA-based stateless hash-based signature construction. The package retains the original technical specification and security discussion of \SPHINCSA\ as supporting material, while reorganizing the repository around the artifacts required by the NGCC public-key algorithm call.

The current package contains three NGCC instances, \texttt{Kylin-128}, \texttt{Kylin-256}, and \texttt{Kylin-512}, together with portable ISO C reference implementations, optimized 64-bit PC implementations, generated known-answer test vectors, automated build scripts, and reproducible parameter-search workflows. The packaged code uses the ICCS SIG API, routes hash/XOF functionality through the ICCS auxiliary interface, and uses the ICCS DRNG interface for KAT-mode randomness. The currently frozen implementation tuples are \texttt{Kylin-128} $(h,d,K,B,t,k,m_{\max},w,\ell)=(56,4,3,15,896,7,136,114,20)$, \texttt{Kylin-256} $(58,4,5,13,1024,7,241,127,38)$, and \texttt{Kylin-512} $(62,4,12,14,192,6,419,125,75)$, while companion $q=2^{24}$ profiles are retained as reference-only additional implementations.
\end{abstract}
